# examples/

Worked examples will live here — a greenfield walkthrough (e.g. "TODO app from scratch") and a brownfield walkthrough (e.g. "fix a bug in an existing repo"). Each example will include the briefs, PRDs, architecture docs, stories, and final code produced by running the agent pipeline.

Not yet populated. Want to contribute one? Pick a small project, run the kickoff, commit the resulting `docs/` tree alongside the code, and open a PR.
